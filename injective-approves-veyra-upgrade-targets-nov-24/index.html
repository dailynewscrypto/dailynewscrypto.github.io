Injective Approves Veyra Upgrade, Targets Nov. 24

Injective’s Veyra upgrade won governance approval and targets a Nov. 24 chain halt, bringing cross-chain transfers and institutional trading tools closer to mainnet.

Crypto Daybook NewsroomNov 21, 2026 · 21:28 UTC2 min read

Injective voters approved the Veyra mainnet upgrade, which targets a Nov. 24 chain halt to install new cross-chain and trading tools. The vote passed on Nov. 16, according to The Defiant’s report on the result.

How did Injective’s Veyra proposal pass?

Proposal 717 received 16,236,896 INJ in yes votes, or 67.5% of all voting power cast. Another 7,745,866 INJ abstained, while 80,589 voted no. Abstentions count toward turnout but not approval; excluding them, yes votes made up 99.51% of voting power.

The vote drew 42.69% participation, above the 33.4% quorum required for a valid result. These figures measure token-weighted voting power, not the number of people who voted. The proposal’s governance record lists it as passed.

Who needs to prepare for the upgrade?

Injective validators, the operators who help run the network and confirm transactions, will need to move to software version v1.21.0. The plan calls for the chain to halt at block 193,145,000 and resume on that version. Injective’s upgrade tracker lists the software and block height as scheduled.

Nov. 24 is a target date tied to when the chain reaches that block. The proposal does not set a time of day. The scheduled halt means validators must coordinate the software change so the network can resume under the new version.

What tools does Veyra add?

The proposal adds Inter-Blockchain Communication (IBC) capabilities to connect Injective’s Ethereum Virtual Machine, which runs Ethereum-compatible contracts, with other connected chains. It also adds request-for-quote tools, which let traders request prices, and expands atomic swaps, a way to exchange assets in one linked transaction.

These changes provide infrastructure for developers, traders and tokenized-asset issuers to build cross-chain and trading applications. They do not themselves launch new assets or guarantee that applications will use the tools.

Veyra also supports work toward CypherOS, Injective’s planned privacy platform. The proposal describes CypherOS as upcoming, so the vote does not mean that privacy platform is launching with this upgrade.
