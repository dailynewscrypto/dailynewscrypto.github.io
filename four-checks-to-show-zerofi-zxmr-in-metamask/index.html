Four Checks to Show ZeroFi zXMR in MetaMask

To show ZeroFi zXMR in MetaMask, check the active network, token contract, receiving address and confirmed transfer; the token may be on Sepolia.

Crypto Daybook NewsroomSep 30, 20262 min read

To show ZeroFi zXMR in MetaMask, check the network, token contract, wallet address and transfer status. MetaMask can display an ERC-20 token, a token built for Ethereum-compatible networks, but it will not show Monero’s native XMR balance. The ZeroFi bridge page currently lists zXMR on Sepolia, Ethereum’s test network, with chain ID 11155111. If you need the deposit and bridge steps, see ZeroFi’s XMR-to-zXMR bridge steps. Once zXMR has reached your wallet, use these four checks to find it.

Is MetaMask on the right network?

Switch MetaMask to Sepolia before looking for the zXMR balance. A token balance belongs to a specific network, so the same wallet address can show different assets on Sepolia and Ethereum mainnet. The ZeroFi page lists chain ID 11155111; check that value if the network name alone is unclear. If Sepolia is missing from MetaMask, enable test networks in its settings or add the network using trusted network details.

A wrong network can make a real token look absent. Switching networks does not move funds or convert XMR; it changes which chain MetaMask is reading.

Does the token contract match?

Import the zXMR contract address published by ZeroFi for the network you selected. The bridge page currently lists 0x60B72Bb62ED83578F00D0C8F7a167c8C0B80Cd88 as its Sepolia zXMR token address. In MetaMask, open the token list, choose the option to import or add a custom token, and paste that address. Confirm the token details before importing.

Token names and symbols are not unique, so searching for “zXMR” by name can return an unrelated asset. The contract address is the useful identifier. If ZeroFi publishes a different address or network, follow its current listing instead of reusing an old one.

Did the bridge send zXMR to this wallet?

Check that the destination address shown in the bridge is the same account selected in MetaMask. Addresses can look alike, so compare the full address carefully before sending. Then check the bridge status and the transaction on the relevant block explorer; a submitted transfer may still be waiting for confirmations before the token arrives.

  • Confirm the receiving address is your MetaMask account.
  • Check the transaction status on Sepolia.
  • Allow time for the bridge and network to finish processing.
  • Make sure the transfer was sent to the zXMR contract’s network.

What if zXMR still does not appear?

First, recheck the active network and the imported contract address. Then refresh MetaMask or remove and reimport the custom token; importing a token only changes how the wallet displays it, not the balance on-chain. If the transaction shows a successful transfer to your account but no balance appears, compare the contract and address shown by the explorer with the details published by ZeroFi.

Keep in mind that zXMR is a wrapped token issued on an EVM network, not native Monero. Its ability to represent XMR depends on the bridge’s operation and redemption process. For most readers, the best check is to verify the network and contract against ZeroFi’s current page before importing, then use the transaction record to confirm the balance belongs to the selected account.
