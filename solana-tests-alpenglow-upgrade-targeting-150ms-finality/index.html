Solana tests Alpenglow upgrade targeting 150ms finality

Solana has put Alpenglow on its public test network, testing a faster way to settle payments that could matter to exchanges and merchants if it works.

The Web3 News DeskSep 24, 20262 min read

Solana has started testing Alpenglow on its public test network, a copy of the blockchain where developers can try changes without risking users’ funds. The upgrade targets cutting “finality”—the point when a transaction can no longer be reversed—from about 12.8 seconds to roughly 150 milliseconds, according to the Solana Foundation.

That shorter wait could help exchanges credit deposits, merchants accept payments and bridges move funds between blockchains sooner. The target is a design goal, though, not a result yet proven on Solana’s main network.

How does Alpenglow aim to shorten the wait?

Alpenglow changes how Solana’s validators agree on which transactions belong in the permanent record. Validators are computers that help run the network. Under the current system, TowerBFT, they cast votes as transactions, and enough votes must build up over 32 slots—about 12.8 seconds—before a block is final, the Solana Foundation says.

The first Alpenglow phase, called Votor, has validators send votes directly to one another and combine them into certificates, or shared proof of agreement. A block can then become final after one or two rounds of voting. The Foundation says transaction execution, fees and the apps people use remain the same.

Solana’s public test network lets developers rehearse the change with a broader set of computers and services than the smaller community cluster used in earlier testing. CoinDesk reported that the testnet migration requires Agave 4.3, the main software for running Solana. It also reported that two alternative validator programs, Firedancer and Frankendancer, do not yet support the test.

What could faster finality change for users?

Today, a business waiting for a payment to become irreversible faces a pause of roughly 13 seconds. At the 150-millisecond target, that would be closer to a blink. Exchanges could confirm deposits sooner, and merchants could get a firmer signal that a payment will not be rolled back.

That does not mean every transaction will feel instant or that all apps will change. The upgrade changes settlement certainty—the point when a payment is locked in—while leaving transaction processing itself alone, according to Solana’s documentation. The actual speed will depend on how the new system performs across validators once testing expands.

When could Alpenglow reach Solana’s main network?

There is no confirmed mainnet launch date. Solana’s upgrade page lists mainnet activation as expected in the third quarter of 2026, tied to Anza’s Agave 4.3 release, but says the main network has not activated Alpenglow. CoinDesk reported that a September 28 software update was tentative and should not be treated as a confirmed launch date.

The open question is whether the test can show that validators with different software and network connections can switch together without disruption—and whether the 150-millisecond target holds under real conditions. Until activation and broader testing, the speedup remains a promise under review.
