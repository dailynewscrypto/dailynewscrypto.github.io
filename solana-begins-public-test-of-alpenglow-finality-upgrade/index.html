Solana begins public test of Alpenglow finality upgrade

Solana has activated Alpenglow on its public testnet, where validators will test a consensus change targeting 150-millisecond finality and faster payment certainty.

Crypto Daybook NewsroomSep 24, 20262 min read

Solana has begun testing Alpenglow on its public testnet, moving the upgrade aimed at much faster transaction finality into a broader trial. CoinDesk’s report on the test says Alpenglow targets a cut from about 12.8 seconds to 150 milliseconds. Solana Foundation’s Alpenglow upgrade tracker now lists the testnet feature gate as active.

Finality is the point when a transaction can no longer be reversed under the network’s consensus rules. Faster finality could let services that wait for that certainty, such as exchanges crediting deposits or bridges releasing funds, act sooner. The 150-millisecond figure is a target, not a guarantee for every transaction.

What changes in Solana’s consensus system?

Alpenglow replaces TowerBFT, Solana’s current system for reaching agreement on blocks, with a voting protocol called Votor. Consensus is the process validators use to agree on which transactions belong in the record.

Under TowerBFT, validators send votes as transactions, and enough votes must accumulate over 32 slots before a block is final. Votor has validators send votes directly to one another and bundle them into certificates. A block can then become final after one or two rounds of voting.

The change is to how validators agree, not how applications execute transactions. Solana Foundation says the upgrade leaves transaction execution, programs and fees unchanged. Users are not being asked to change how they send funds.

What does the testnet launch confirm?

The public testnet is a separate version of Solana where developers and validators can try the migration before it reaches the main network. The Foundation’s tracker marks the testnet feature gate active, while the devnet and mainnet gates remain inactive.

The trial tests whether the wider set of computers and services running Solana can move to the new consensus system together. Alpenglow had also been tested on a community cluster, a smaller network used to rehearse the switch.

When could Alpenglow reach Solana’s main network?

It has not activated on mainnet. CoinDesk reported that Sept. 28 was a tentative date for activating features in Agave 4.3, Solana’s main validator software, and was not a confirmed Alpenglow launch date. The Foundation’s tracker lists Q3 2026 as the expected mainnet activation window.

The timing and finality speed remain subject to testing. The Foundation says the 150-millisecond estimate depends on the network’s stake distribution and can vary with whether a block finalizes in one or two rounds. The public testnet is a step toward a mainnet rollout, not proof that the target has been reached there.
