Should I speed up a pending bridge deposit or wait?

Speed up or wait on a pending bridge deposit transaction? Raise the fee only while the source transaction is pending and underpriced; once confirmed, wait.

Crypto Daybook NewsroomNov 23, 2026 · 19:16 UTC3 min read

Speed up a pending bridge deposit only while its source-chain transaction is unconfirmed and underpriced; once it confirms, wait for the bridge because relaying and delivery happen afterward. A wallet’s “pending” label and a bridge transfer that is still processing refer to different stages, so first check the transaction on its source chain.

Three checks decide the next step

Source transaction status

Look up the transaction on a block explorer such as Etherscan for Ethereum, or the explorer for BNB Chain. If it is still pending, the deposit has not yet reached the bridge. If it is confirmed, the source-chain step is complete, even if the destination wallet has not received the assets.

Consider two deposits with the same asset and destination. In the first, the source transaction is pending and its fee is below the current base fee. A speed-up can help that transaction get included. In the second, the transaction has already confirmed, but the bridge transfer is still waiting. Paying for a speed-up cannot change that confirmed transaction, so the right move is to wait and track the transfer in cBridge.

Fee compared with the current base fee

Speeding up resubmits the same transaction nonce, a sequence number the wallet uses, with a higher fee to replace the original. It costs extra gas. This can clear a deposit whose fee became too low after base fees rose. Nodes commonly require a bump of at least about 10% to accept a replacement, though the required increase can vary.

After a speed-up, the original hash may show as “dropped and replaced” on a block explorer. That means the original transaction was replaced; it does not mean the deposit completed. Track the replacement hash, because that is the transaction that can confirm.

Once the source transaction confirms, use cBridge as the next place to track the transfer, because relay and delivery happen after the source-chain step. The State Guardian Network is part of this later bridge stage, so raising an Ethereum or BNB Chain fee cannot speed up a relay that is already pending.

Whether you still want the transfer

If the transaction is pending and underpriced, speed up when you still want the deposit. If the fee is adequate and there is no reason to rush, waiting avoids paying extra gas. If you no longer want the transfer and it is still pending, you can try to cancel it with a zero-value transaction using the same nonce. If that cancellation replaces the original, no transfer happens.

Related

How long does a cBridge transfer take?

It depends on the stages involved. First the source transaction must confirm; then the bridge relays and delivers the transfer. Check the source transaction before treating a bridge delay as a wallet fee problem.

What does “dropped and replaced” mean on a block explorer?

It means a replacement transaction was submitted with the same nonce. Follow the replacement hash to see whether it confirms. A useful habit is to save that hash after a speed-up, which avoids tracking the original transaction after it has been replaced.
