Injective’s Veyra upgrade adds tools for institutional asset trading

Injective’s Veyra upgrade went live at block 193,145,000, adding cross-chain transfers and quote-based trading tools for institutional tokenized assets.

Crypto Daybook NewsroomNov 26, 2026 · 15:46 UTC2 min read

Injective activated its Veyra mainnet upgrade at block height 193,145,000 on Nov. 24, adding cross-chain transfers and trading tools for institutions handling tokenized assets, according to crypto.news’ report. The network moved to software version v1.21.0.

Veyra’s governance proposal says the upgrade adds Inter-Blockchain Communication (IBC) support for assets issued in Injective’s Ethereum Virtual Machine (EVM) environment. IBC is a protocol for transferring data and assets between connected blockchains. The change lets those EVM assets move to other connected networks, where they can reach different trading and financial applications.

Real-world assets, or RWAs, are traditional assets represented as digital tokens. Injective’s proposal says the new transfer support is intended to help institutions issue and trade tokenized financial products across chains. It does not name specific assets or issuers that will use the feature.

Veyra also adds request-for-quote (RFQ) trading infrastructure. With RFQ, a trader asks liquidity providers for prices before committing to a trade. That gives institutions another way to handle orders alongside Injective’s onchain order book. The proposal also describes expanded atomic swaps, in which both sides of an asset exchange settle together.

The upgrade passed as proposal IIP-717. Voting ran from Nov. 12 to Nov. 16, and the proposal received 16.24 million INJ votes in favor and 80,589 against. Excluding abstentions, that was about 99.51% support, crypto.news reported. Voter participation was 42.60%, above the 33.40% quorum required for a valid vote.

Veyra builds on Injective Institutional Rail, an access layer for financial firms that the network introduced on Nov. 2, according to crypto.news. The upgrade also lays groundwork for CypherOS, Injective’s planned privacy platform. The proposal says Veyra prepares the network for that work; it does not say CypherOS went live with this upgrade.

The changes extend the network’s support for moving, trading and settling tokenized assets. Their practical reach will depend on which issuers, institutions and applications adopt the new tools.
