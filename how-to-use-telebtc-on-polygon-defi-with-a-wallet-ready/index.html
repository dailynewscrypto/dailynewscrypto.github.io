How to use teleBTC on Polygon DeFi with a wallet ready

How to use teleBTC on Polygon DeFi: connect your wallet, find an app that supports it, then swap, supply to a pool or lend where available, with Polygon gas.

Crypto Daybook NewsroomNov 19, 2026 · 15:35 UTC3 min read

teleBTC lets you use Bitcoin-linked value in Polygon DeFi by holding the token on Polygon and choosing an app that supports it for a swap, pool deposit, or lending action.

Say your wallet already holds teleBTC on Polygon and you want to use that value in a DeFi app. The token represents Bitcoin-linked value on Polygon, so the app can work with it there without handling a native Bitcoin transaction. TeleSwap is one part of the transfer story: how TeleSwap moves BTC to teleBTC is a concrete case of its Bitcoin-EVM bridge using collateralized Lockers, which provide collateral in the bridge system.

That distinction matters because Polygon apps interact with tokens on Polygon, while native BTC is on Bitcoin. Once teleBTC is on Polygon, the app’s available actions depend on whether it supports the token for the action you want.

Use teleBTC only in a Polygon app that supports it

In a supporting Polygon app, select teleBTC as the token to swap or as an asset to supply to a pool or lending market. Picture a new Bitcoin holder who wants to put some Bitcoin-linked value to work in a Polygon pool: they can choose teleBTC as the asset to supply, review the transaction, and confirm it in their wallet. This is an illustrative case; the available pool or other action depends on current app support.

To start, you need a wallet that can connect to Polygon and Polygon’s native gas token for transaction fees. Connect the wallet to Polygon, then confirm teleBTC appears in its Polygon token view. Open a Polygon DeFi app that lists teleBTC for your intended action. Review the transaction details before confirming it in the wallet.

A plain 0x wallet address is shared across Ethereum, Polygon, and BNB Smart Chain. So teleBTC may be in your wallet even while it displays another network. If the token does not appear, check the selected network and switch to Polygon. Then confirm that the app supports teleBTC for your chosen action before submitting a transaction.

Related questions

Can you swap teleBTC on Polygon?

You can swap teleBTC on Polygon in an app that lists it as a supported token for swaps. Check the selected network and the app’s token choices before you confirm the transaction.

What wallet do you need for Polygon DeFi?

You need a wallet that can connect to Polygon and hold the Polygon gas token for fees. The same 0x address can appear on multiple networks, so check that the wallet is connected to Polygon and shows teleBTC there.

Does your Polygon app list teleBTC for the action you want, and does your wallet show Polygon as the selected network? Those answers determine whether you can use the token in that app now; if either answer is no, you’ll need a supporting app or the correct network before proceeding.
