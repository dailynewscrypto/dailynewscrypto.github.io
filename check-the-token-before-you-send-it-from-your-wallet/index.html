Check the token before you send it from your wallet

Check the token name, network and contract address before sending. These quick steps can help you avoid sending an asset to the wrong place.

Crypto Daybook NewsroomOct 17, 2026 · 01:57 UTC3 min read

Before sending crypto, check the asset, network and recipient shown in your wallet; a familiar token name alone does not prove it is the right one. Tokens with the same name or symbol can exist at different contract addresses, and a transfer sent to the wrong place may be hard or impossible to recover. If you are moving funds across chains, this guide to relay bridge gas for frequent traders explains what can happen when the destination wallet lacks gas. For a normal wallet transfer, use the checks below before you confirm.

How do I know I have the right token?

Match the token’s contract address on the network you are using against a trusted source. A contract address is the identifier for the token’s code and balances on that network. Get it from the project’s official site or a reputable block explorer, a site that lets you inspect blockchain records. Do not rely on a search result, a token logo or a symbol such as “USDC” by itself; lookalike tokens can use familiar names.

Check that the wallet is set to the network where you hold the asset. A token may have versions on several networks, each with its own contract address. The same wallet address can appear on more than one network, but that does not mean the recipient can use every version of a token. If the recipient is an exchange, check its deposit instructions for the exact network and asset it supports.

What should I check on the send screen?

Read the details in the wallet’s confirmation screen, then compare them with the payment request. Check the selected asset, amount, recipient address, network and estimated fee. The fee is paid to process the transaction; depending on the network and wallet, it may be charged in the network’s native coin or another supported token.

  • Confirm the token name and network match the recipient’s instructions.
  • Compare the full recipient address, especially the first and last characters.
  • Check the amount and fee before signing.
  • If you copied the address, make sure it did not change when pasted.

When possible, verify the address through a second trusted channel, such as a saved contact or a fresh message to the recipient. A small test transfer can help with a new address or network, though it costs an extra fee and does not guarantee that a larger transfer will work.

What if the token or address looks different?

Pause if the wallet shows an unfamiliar token, a contract warning or a network you did not expect. A contract warning can mean the destination is the token’s own contract address, which is usually not where a person should receive a transfer. Check the address and network with the recipient before proceeding. A confirmed blockchain transfer generally cannot be reversed by the wallet provider.

The safest routine is simple: identify the token by its contract on the correct network, then check the destination and fee on the final screen. If any detail does not match the payment instructions, do not sign until you have verified it.
