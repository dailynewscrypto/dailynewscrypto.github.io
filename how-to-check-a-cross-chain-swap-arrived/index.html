How to check a cross-chain swap arrived

A cross-chain swap can leave one confirmed transaction and another still pending. Check both chain records, the destination address and token before acting.

Crypto Daybook NewsroomOct 16, 2026 · 03:05 UTC3 min read

To check that a cross-chain swap arrived, verify the destination transaction on its own network and match the token and amount to your order. A confirmed transaction on the source chain only shows that the swap started; the destination transfer may still be processing. Keep the order receipt or source transaction ID handy. They help you follow the swap when the two networks use separate records.

What should I check first?

Start with the swap page or receipt, then compare its details with the destination wallet. For route choices and the steps between chains, the fuller guide to thor swap explains the handoff; this check is about confirming the final receipt. Look for a destination transaction ID, a status such as pending or complete, and the exact destination network. A transaction ID is a unique reference you can search in a block explorer, a site that displays public blockchain records.

Before treating the swap as received, match these details:

  • The destination network is the one selected for the swap.
  • The receiving address matches your wallet on that network.
  • The token is the intended asset, including its network or token version.
  • The received amount is consistent with the quote and any fees shown.

A token can have similar names to other assets, so check its contract or asset details if the wallet lists more than one version. A balance may also be hidden until the token is added to the wallet view.

How do I check the destination transaction?

Open the destination transaction ID in an explorer for that network. Check that its status is successful, the receiving address is yours, and the token transfer and amount fit the receipt. On networks that show confirmations, more confirmations mean the transaction has been included in more blocks. The wait needed for confidence varies by network and service, so use the swap page’s status and the network’s own indicators rather than applying one universal number.

If the swap page gives only a source transaction ID, search that ID on the source network first. Then use the swap’s order details or status page to find whether a destination transaction has been created. The two sides of a cross-chain swap often have different transaction IDs because each network records its own activity.

What if the swap is still pending or missing?

A pending destination leg does not by itself mean the swap failed. The source transaction may be confirmed while the service or protocol waits to complete the next step. Check the status page again after the time it gives for processing, and search the destination address in the correct network’s explorer. A successful transfer may not appear in a wallet if it is showing another network or has not added that token.

If the destination record is marked failed, or the stated processing time has passed with no destination transaction, save the receipt and both transaction IDs. Use the swap service’s official support route and share only the public transaction details it needs. Never share a wallet recovery phrase or private key to prove a transaction.
