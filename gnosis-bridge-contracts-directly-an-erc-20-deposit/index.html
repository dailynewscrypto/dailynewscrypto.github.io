Gnosis Bridge contracts directly: an ERC-20 deposit

Learn how to use Gnosis Bridge contracts directly without the website: approve the Omnibridge mediator, call relayTokens, and track the ERC-20 on GnosisScan.

Crypto Daybook NewsroomNov 24, 2026 · 08:09 UTC3 min read

Gnosis Bridge contracts let you send an ERC-20 from Ethereum to Gnosis Chain by approving the Omnibridge mediator, then calling relayTokens directly. The website builds these same contract calls, so gnosisbridge.org is a practical example of the same flow through its direct token transfer feature.

Have ready: The token in an Ethereum wallet connected through MetaMask, ETH for Ethereum gas, the token’s decimals, and the Ethereum mediator address from the official Gnosis docs. The docs list the Omnibridge Multi-Token Mediator Proxy at 0x88ad09518695c6c3712AC10a214bE5109a655671. Open that address on Etherscan and confirm you have the verified contract page before connecting your wallet.

How do you send an ERC-20 through Gnosis Bridge contracts?

  1. Approve the mediator. Open the token contract on Etherscan and use its write functions to call approve. Enter the mediator as spender and the amount in base units. Base units are the smallest token units, set by decimals: for a six-decimal token such as USDC, 1 token is 1,000,000 units. Confirm the transaction in MetaMask. The visible result is an approval allowing the mediator to transfer up to that amount; the token balance has not yet moved.
  2. Call the proxy function. Open the mediator address on Etherscan and connect the wallet that holds the token. Omnibridge is an upgradeable proxy: it keeps the public address while delegating calls to an implementation contract. Use the Write as Proxy tab to access that implementation’s functions at the proxy address. Plain Write Contract can show only proxy admin functions, which is why relayTokens may be missing there. Call relayTokens(token, receiver, amount) with the Ethereum token address, the Gnosis Chain recipient, and the same base-unit amount. Confirm the transaction. The visible result is a submitted Ethereum transaction and a bridge message for validators to relay.
  3. Wait for the relay and confirm arrival. Search for the transaction or recipient on GnosisScan. Before the call, the tokens were in the Ethereum wallet and no matching bridged balance was visible for the receiver on Gnosis Chain. After validators relay the message, the bridged token balance appears for that recipient on GnosisScan. The task is complete when the expected token and amount are visible there; the source balance and destination balance are on separate networks.

A withdrawal from Gnosis Chain to Ethereum has a claim step. After validators sign the message, call executeSignatures on the Ethereum Arbitrary Message Bridge (AMB) with the validator-signed message and signatures. That claim completes the return transfer.

Related questions

How to bridge DAI to xDAI through the xDai Bridge contract?

Omnibridge transfers DAI as a bridged token; it does not turn DAI into native xDAI. For native xDAI, use the xDai Bridge route described in the official Gnosis materials.

Can a Safe multisig call Gnosis Bridge contracts?

Yes. A Safe can submit the approval and relayTokens calls as transactions. The Safe must hold the ERC-20, because the mediator can transfer tokens only after that token-holding address approves it.
