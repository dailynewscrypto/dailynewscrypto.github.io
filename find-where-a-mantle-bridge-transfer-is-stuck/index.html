Find where a Mantle bridge transfer is stuck

A stuck Mantle transfer may be waiting on a source transaction, destination processing or a withdrawal claim. Check each step before sending funds again.

Crypto Daybook NewsroomSep 29, 20263 min read

To diagnose a stuck Mantle transfer, find its transaction hash and check which step has completed on the sending and receiving networks. A bridge transfer can involve separate on-chain transactions, so a wallet message alone may not show where the funds are. Deposits move assets from Ethereum to Mantle; withdrawals move them back and require a separate claim when the bridge marks them ready.

How do I check whether the transfer started?

Open the bridge’s history and find the transfer using the connected wallet. Check whether the wallet confirmed a deposit or withdrawal transaction, and copy its transaction hash. A fuller explanation of the transfer flow is in Mantle Bridge. If you approved a token but never confirmed the deposit, the approval only allows the bridge contract to use that token; it does not send the funds.

Look up the hash on the explorer for the network where the transaction began. A pending transaction has not been included in a block yet. A failed transaction did not complete, and its error or execution details may explain why. A successful source transaction means that step finished, but the destination transfer may still be processing.

Why has a deposit not appeared on Mantle?

A deposit can take time after the Ethereum transaction succeeds because the bridge must process its message on Mantle. Check the destination address and look up that address on Mantle’s explorer. Make sure the wallet is showing the Mantle network and the same address that received the bridge transfer.

If the destination transaction is complete but the balance is missing, check that the token is supported and that the wallet is displaying the right token. The same ticker can refer to different token contracts, so verify the token’s Mantle contract through a trusted source before adding it to a wallet. Also check Mantle’s network status for a reported bridge or network issue.

Why is a withdrawal waiting for a claim?

A withdrawal does not put funds back on Ethereum as soon as its Mantle transaction succeeds. The bridge must first settle the withdrawal on Ethereum; once it is ready, you need to send a separate claim transaction from the same wallet. Check the bridge’s history for the withdrawal status, and look up the withdrawal transaction on Mantle if it does not appear there.

The claim costs Ethereum gas, so the wallet needs ETH on Ethereum even when the withdrawal itself is ETH. If the bridge says the withdrawal is ready, switch networks and submit the claim. If it is still processing, wait for the status to change rather than starting a duplicate withdrawal.

What should I check before trying again?

Use the transaction status to decide what action is safe. Before resubmitting, confirm which of these steps is actually missing:

  • Source transaction: Check whether it is pending, failed or successful on the source network.
  • Destination message: If the source succeeded, check the receiving address and destination explorer.
  • Withdrawal claim: If the withdrawal is ready, check that the wallet has ETH for the Ethereum claim.

Do not share a seed phrase or private key with anyone offering to “release” a transfer. Keep the transaction hash, use the bridge’s own history, and contact official support if the on-chain status and bridge status do not match. A successful transaction on one network does not by itself prove that every bridge step is finished.
